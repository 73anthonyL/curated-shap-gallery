# Curated SHAP gallery

SHAP waterfall and beeswarm plots for 34 hand-written curated texts under each of the 8 techniques of [extremism_sentiment_analysis](https://github.com/73anthonyL/extremism_sentiment_analysis). Open `index.html`; `method.html` explains how the plots were made.

Built by `tools/curated_site.py` from the gallery of `tools/curated_plots.py`. The curated texts are not dataset rows; they illustrate model behaviour and support no accuracy claim. This is not a moderation tool.
